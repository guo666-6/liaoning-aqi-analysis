辽宁省城市空气质量时空特征可视化分析

基于2025年辽宁省14个地级市122,640条小时级空气质量监测数据，运用Python完成数据清洗、特征工程与多维可视化分析。

核心发现

- **空间格局**：辽中南城市群污染最重（营口AQI=100），呈现"中部高、两翼低"分布
- **时间规律**：冬季AQI为夏季2倍，呈"U型"趋势
- **关键因子**：PM2.5与AQI相关性最强（r=0.687）

## 技术栈

Python / Pandas / NumPy / Seaborn / Matplotlib / Plotly / Scikit-learn
