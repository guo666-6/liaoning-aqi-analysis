# 辽宁省城市空气质量时空特征可视化分析

## 项目背景

辽宁省是我国重要的老工业基地，重工业企业集中、能源结构以煤炭为主，大气污染防治压力较大。2025年，全省14个地级市已实现国控空气质量监测站点全覆盖，形成了海量的小时级监测数据集。

本项目基于该年度监测数据，运用聚类分析和多维可视化方法，系统分析辽宁省空气质量的时空分布规律及影响因素，为差异化环境治理提供数据支撑。


## 数据说明

| 项目 | 说明 |
|:---|:---|
| 数据来源 | 辽宁省生态环境监测中心公开数据 |
| 监测标准 | 《环境空气质量标准》（GB 3095-2012） |
| 覆盖范围 | 14个地级市 |
| 监测指标 | PM10、PM2.5、CO、NO₂、SO₂、O₃、AQI |
| 时间粒度 | 小时级（2025年1月1日 — 2025年12月31日） |
| 记录总量 | 122,640条（14城市 × 365天 × 24小时） |
| 数据质量 | 完整率100%，无缺失值 |


## 分析框架

数据获取 → 数据清洗 → 特征工程 → 多维分析 → 可视化呈现 → 结论输出

**分析方法**：
- 聚类分析：Ward层次聚类，识别污染模式相似的城市群
- 时序分析：月度/季节粒度，揭示污染的季节性规律
- 关联分析：Pearson相关系数，识别AQI的首要驱动因子


## 核心结论

### 1. 空间格局：中部高、两翼低

层次聚类将14个城市分为三类：
- **高污染区**（辽中南城市群）：沈阳、鞍山、营口、辽阳。营口年均AQI为100，全省最高
- **中污染区**：抚顺、本溪、盘锦、铁岭、大连
- **低污染区**：丹东、朝阳、葫芦岛、锦州、阜新。朝阳年均AQI为47.8，全省最低

### 2. 时间规律：U型趋势，冬季为夏季的2倍

所有城市AQI月度变化均呈现"U型"特征。夏季（7-8月）为全年最低值，冬季（12-2月）为全年峰值，与采暖期高度吻合。沈阳、鞍山等城市冬季峰值可达100以上，而丹东冬季峰值仅70左右，表明不同城市的采暖污染管控效果存在明显差距。

### 3. 关键驱动因子：PM2.5是首要控制对象

相关性分析表明，PM2.5与AQI的相关系数为0.687，为所有污染物中最强。O₃与AQI呈负相关（r=-0.143），反映"臭氧悖论"现象——高温强光照有利于O₃生成，但同时有利于污染物扩散，导致一次污染与二次污染此消彼长。


## 业务建议

| 优先级 | 建议 | 依据 |
|:---:|:---|:---|
| 1 | 辽中南城市群实施更严格的工业排放标准 | 该区域PM2.5和SO₂浓度显著高于其他地区 |
| 2 | 采暖期（11月-次年3月）启动应急减排预案 | 冬季AQI为夏季的2倍 |
| 3 | 优先控制PM2.5及其前体物排放 | PM2.5是AQI的首要驱动因子（r=0.687） |
| 4 | 重点排查营口市SO₂异常排放源 | 营口SO₂年均值186μg/m³，为全省均值4倍 |
